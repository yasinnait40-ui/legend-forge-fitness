# Aethora's Legend

AETHORA — IMMERSIVE FANTASY FITNESS RPG



Build the application AETHORA — Forge Your Legend as a visually rich, cinematic fantasy fitness RPG.



This is NOT a normal fitness dashboard.



The application must look and feel like a real premium fantasy RPG game, while remaining a functional fitness application.



MOST IMPORTANT VISUAL REQUIREMENT



DO NOT create screens that are simply:



- Black background

- Text

- Cards

- Logos

- Basic gradients

- Generic icons



Every major screen must contain actual fantasy visual artwork, atmospheric backgrounds, characters, weapons, magical environments, or detailed fantasy illustrations.



The user should immediately feel that they entered a fantasy world.



Use image assets, generated artwork, available image-generation capabilities, or high-quality fantasy assets supported by the platform.



Do not use placeholder rectangles where a real visual should exist.



---



VISUAL STYLE



Create a sophisticated dark fantasy RPG aesthetic.



Visual references should include:



- Ancient castles

- Magical forests

- Mountains

- Ancient ruins

- Wizard towers

- Arcane libraries

- Underground dungeons

- Glowing magical crystals

- Ancient books

- Floating magical runes

- Swords

- Shields

- Armor

- Fantasy characters

- Mystical creatures

- Magical portals

- Fire and magical energy

- Fog

- Moonlight

- Cinematic landscapes



The visual style should feel:



Epic + mysterious + magical + premium + cinematic



Avoid childish cartoon fantasy.



Avoid generic AI-looking fantasy art.



Prefer cohesive artwork with a consistent visual identity across the entire application.



---



AETHORA WORLD



AETHORA should feel like a world.



The application should visually communicate that the user is an adventurer progressing through a magical realm.



Every section should have its own environment.

AI:

An ancient wizard sitting inside a massive arcane library.

ARCANE GUIDE — AI



This is one of the most important parts of AETHORA.



Do NOT make the AI screen look like a normal ChatGPT interface.



The user should enter an ancient magical library.



Place an elderly, wise fantasy wizard/mage sitting at a large wooden desk.



Around him:



- Ancient books

- Floating magical runes

- Candles

- Glowing crystals

- Scrolls

- Potions

- Magical blue/purple light

- Shelves filled with ancient books



The wizard is the Arcane Guide.



He is the AI mentor of AETHORA.



The wizard should feel wise, calm, mysterious, and helpful.



Use the AI to answer questions about:



- Workouts

- Fitness

- Exercise technique

- Nutrition basics

- Recovery

- Motivation

- Training plans

- Healthy habits



Example greeting:



"You have returned, traveler. What shall we improve today?"



Keep the fantasy personality subtle and natural.



Do not make every response theatrical.



---



AI VISUAL INTERACTION



When the AI is generating an answer:



Show subtle magical effects around the wizard.



Examples:



- Floating runes

- Glowing crystal

- Magical particles

- Subtle spell animation



When the AI responds:



The wizard should visually feel like he is speaking to the user.



Keep animations lightweight so the application remains fast.



---



AI INTEGRATION



Use Google Gemini through the platform's available integration.

Use a secure environment variable:

NEVER expose the API key in frontend code.



NEVER place it directly inside the application source code.



NEVER display it to users.



Use secure server-side communication whenever required.



Implement:



- Chat history

- Conversation context

- New conversation

- Loading state

- Error handling

- Retry

- Suggested prompts



Suggested prompts:

"Build me a workout."



"I only have 20 minutes."

MOBILE DESIGN

A premium fantasy RPG + fitness application

A fitness app with purple gradients.

A black screen with text.

A chatbot with a fantasy background.

A generic dashboard template.

---



CRITICAL IMPLEMENTATION RULE



Before generating the UI:



1. Plan the visual identity.

2. Create/select the fantasy artwork required for each major screen.

3. Build the interface around the artwork.

4. Integrate the functional fitness systems.

5. Integrate the Arcane Guide AI.

6. Add subtl APIe animations.

7. Test the complete mobile experience.



Do not create the basic UI first and add random images afterward.



The artwork and interface must be designed together.
